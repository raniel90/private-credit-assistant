# Product

## Register

product

## Users

Developers and reviewers exploring a private credit assistant with retrieval,
agent orchestration and inspectable access controls.

## Product Purpose

Demonstrate a fictional loan scenario through chat. Make tool execution,
supporting evidence and backend access decisions inspectable. Distinguish
demonstrated behavior from production capabilities not yet implemented.

## Brand Personality

Independent, neutral and precise. Use the generic Credit Desk identity, a dark
interface and American English. Do not include real client names or branding.

## Design Principles

Keep the conversation primary and the composer compact. Make evidence and tool
execution easy to inspect. Show the active demo profile and access limitations.
Avoid decorative cards, marketing language and implied financial approval.

## Accessibility & Inclusion

Preserve keyboard access, visible focus, responsive layout and reduced motion.
Use WCAG AA text contrast as the implementation baseline.
